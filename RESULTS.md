## Interpretation

The project treats intent classification as an operational routing decision. The preferred model should balance class-level quality with automation coverage, confidence reliability, latency, and serving cost rather than being selected from accuracy alone.

In this verified run, TF-IDF + Logistic Regression is the strongest production candidate: it achieved the best test accuracy and macro-F1 while still auto-routing most requests at high accuracy. The one-epoch DistilBERT run completed successfully but was clearly under-trained, so it is retained as a truthful PyTorch/Transformer benchmark rather than presented as the best model.
